## The Axis engine

Apalia was an HTML5 game built under contract for Intel's short-lived AppUp platform, designed by my friend James Booth. The design called for a specific set of features, and nothing available at the time provided them, so I wrote a custom JavaScript engine to fit. This was before WebGL — Canvas2D was the only option in the browser — and for its era it was an unusually capable engine as browser engines went.

<Video id="7rtGwHu5flo" />

## Engine features

Everything below was written from scratch, with no libraries or existing frameworks underneath it:

- Sprites with time-based animation
- Thousands of animated sprites on screen at once
- Camera with configurable delay and follow-actor behavior
- Infinite layers with switching between them
- Polygon-based path system
- Sphere, box, and polygon collisions
- Event system with custom events
- Input across 150+ key combinations, mouse, and touch
- Basic behavior-tree AI

- Scene management
- Dialogue-tree system with 670+ customization possibilities
- Media resource manager, with background downloading and memory freeing
- In-game HTML5 audio and video manager
- Timers with chained commands
- Runs on desktop, browsers, and phones

## Wins and struggles

I was excited for the work, and I had no idea how far in over my head I was. It became clear quickly how large a task building your own engine is, even in the browser. I was the sole programmer, and it was hard work, but I learned an enormous amount and became a real developer in the process. Everything was coded from scratch, using no libraries or existing frameworks, and I remain proud of what came out of it.
